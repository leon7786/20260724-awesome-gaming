# Steam 游戏榜单整理指南 (Top 250 & 实时热销榜)

## 一、概述
在 Steam 平台及第三方数据网站中，“Steam Top 250” 主要存在两种不同维度的榜单：
1. **Steam 250（玩家好评率/口碑排行榜）**：基于用户评价加权算法计算出的史上最高评价游戏榜单（[steam250.com](https://steam250.com/)）。
2. **SteamDB / Steam 官方热销榜（ Global Top Sellers ）**：基于游戏销售总收益（含游戏本体销量、DLC 及内购）排序的实时销量榜。

## 三、Steam / SteamDB 实时销量与收益大作（Global Top Sellers）

Steam 官方销量榜按总收入排序，涵盖免费内购网游与买断制大作：

### 1. 长期高收益/高在线大作（包含免费内购）
- **Counter-Strike 2 (CS2)**：Steam 长期在线人数与内购营收冠军。
- **Dota 2**：Valve 经典 MOBA 游戏。
- **PUBG: BATTLEGROUNDS**：战术竞技鼻祖，免费化后保持强劲收益。
- **Apex Legends**：高质量战术竞技射击游戏。

### 2. 畅销买断制单机/联机大作
- **Palworld (幻兽帕鲁)**：爆款开放世界怪物抓捕与生存建造。
- **Baldur's Gate 3 (博德之门 3)**：年度最佳 RPG，单机销量口碑双丰收。
- **Black Myth: Wukong (黑神话：悟空)**：打破多项销量与在线纪录的国产西游题材 3A 动作 RPG。
- **Elden Ring (艾尔登法环)**：FromSoftware 开放世界魂系巅峰之作。
- **Grand Theft Auto V (GTA V)**：跨世代长青销量奇迹。
- **Cyberpunk 2077 (赛博朋克 2077)**：夜之城开放世界 RPG。
