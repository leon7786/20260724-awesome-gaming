关于此游戏

一年之中最期待的游戏，史上最畅销的第一人称动作游戏续作 Modern Warfare 2（现代战争 2 ）延续了扣人心弦的故事情节，并将玩家带领到面临崩溃的世界去战胜新的威胁。
Call of Duty®: Modern Warfare 2（使命召唤：现代战争 2）第一次在视频游戏中请来曾经获得奥斯卡金像奖、金球奖、格莱美音乐大奖以及多项大奖的 Hans Zimmer 为游戏配乐。前作使命召唤 4：现代战争®曾经风靡全球，引起全世界的好评。其中包括：
  • “最多玩家在线的视频游戏”，2009 年吉尼斯世界纪录
  • 超过 50 个年度游戏大奖，包括最佳电视游戏奖和年度最佳游戏，2007 年，互动科学艺术学院

特别行动

全新的游戏模式，让两名玩家共同完成单人战役。
  • 特别行动里在基础任务上添加了计时赛，让玩家去挑战每次任务完成时间。
  • 等级晋升，让玩家在特别行动里解锁一个又一个困难的任务。
  • 任务主要包含了单人战役。粉丝们最爱的使命召唤 4：现代战争里才有的特别任务。

系统需求

最低配置

  • 操作系统：Microsoft Windows XP 或 Windows Vista（不支持 Windows 95/98/ME/2000）
  • 处理器：英特尔奔腾 4 3.2 GHz 或 AMD 速龙 64 3200+ 处理器或可支持的更高处理器
  • 内存：1 GB RAM
  • 显卡：256 MB 英伟达 GeForce 6600GT 或更高或 ATI Radeon 1600XT 或更高
  • DirectX®：Microsoft DirectX(R) 9.0c
  • 硬盘剩余空间：12GB 可用硬盘空间
  • 声卡：DirectX 9.0c 100% 兼容声卡
  • 互联网连接：多人游戏需要宽带连接和服务。激活游戏需要互联网连接。
  • 合作/多人游戏主机：要建立合作或多人游戏主机，建议使用 2Ghz 多核处理器或更高的处理器。
