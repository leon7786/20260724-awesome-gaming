关于此游戏

Call of Duty® 在屏幕上逼真重现第二次世界大战，同时展现出电影般的紧凑节奏，突破以往表现，让您通过小兵的视界，无名英雄的双眼，见证战场的猛烈，参与多国联盟，一起塑造现代历史的进程。

扮演训练精良的小队成员，在战场的混乱里提供火力掩护，火线救护受伤战友。 游戏中除了逼真的小队动作与战术，战场上还可以看到每一名士兵的个性和训练成果。

战争胜利并不是靠一名士兵或一个国家赢得。 Call of Duty® 首次从多个角度描绘大战，包括了美国、英国和苏联的士兵。 执行 24 个任务，体验共 4 个互相关联的历史性战役。 任务目标多变，包括破坏、全面突袭、秘密行动、战车争霸和救援任务。 逼真的武器、地点、战车和音效，一切都将逼真度提升到极至，让您享受至今最完美的二次世界大战体验。

系统需求

最低配置

最低配置： 必须带有 3D 硬件加速卡 - 100% DirecX 9.0b 兼容 32 MB、具备硬件 T&L 功能的显示卡和最新驱动程序*，英文版 Microsoft Windows 98/ME/2000/XP，Pentium III 600MHz 或 Athlon 600MHz 处理器或更高系统配置 Windows 98/ME，Pentium III 700MHz 或 Athlon 700MHz 处理器或更高系统配置 Windows 2000/XP，128MB 内存，1.4GB 未压缩可用硬盘空间（另需 400MB 供 Windows 98/ME 用于交换文件，600MB 供 Windows 2000/XP 用于交换文件），100% DirectX 9.0b 兼容 16 位声卡和最新驱动程序，100% Windows 98/ME/2000/XP 兼容鼠标、键盘和最新驱动程序，DirectX 9.0b（随附）
多人游戏要求：
  • 支持 Internet (TCP/IP) 和局域网络 (LAN TCP/IP) 游戏
  • Internet 游戏需要 56kbps（或更高速）调制解调器和最新驱动程序
  • LAN 游戏需要网卡和最新驱动程序
重要：*部份 3D 加速卡虽然使用此处列出的芯片组，但不一定与 Call of Duty 所使用的 3D 加速功能兼容。 请向硬件制造商咨询是否完全兼容 DirectX 9.0b。

  • 所有 ATI Radeon 显示卡
